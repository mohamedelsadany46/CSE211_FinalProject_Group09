## Project Overview

**EventsX** is a web-based event planning and registration platform developed as part of the CSE211 Web Programming course.
The system allows users to browse upcoming events, view event details, calculate event budgets, and register for events through an interactive and user-friendly interface.

The project demonstrates the practical use of **HTML5**, **CSS3**, **JavaScript**, and **PHP/MySQL** following modern web development principles.

---

## Features

* Browse upcoming events
* View events in card and table formats
* Event registration form with validation
* Budget calculator for estimating event costs
* Contact and About pages
* Responsive design for different screen sizes
* Backend integration using PHP and MySQL (local environment)

## Deployment Notes

Due to the limitations of static hosting platforms such as **tiiny.host**, PHP and MySQL cannot run online.

* Backend functionality is fully demonstrated **locally**
* Online deployment uses **static JSON files** to simulate backend responses
* Screenshots are provided to demonstrate backend execution and database interaction

---

## How to Run Locally

1. Install XAMPP
2. Start Apache and MySQL
3. Import the provided SQL file into phpMyAdmin
4. Place the project folder inside `htdocs`
5. Open the project using:

   ```
   http://localhost/EventsX/
   ```
